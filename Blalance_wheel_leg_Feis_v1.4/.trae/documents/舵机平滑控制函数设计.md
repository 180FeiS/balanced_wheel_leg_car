# 舵机平滑控制函数封装设计

## 设计思路

基于用户的要求，我将设计一个独立、可复用的舵机平滑控制函数，该函数能够在中断服务程序中安全调用。具体设计思路如下：

1. 设计一个结构体来存储舵机平滑控制的状态信息
2. 实现初始化函数，配置平滑控制参数
3. 实现更新函数，在中断服务程序中调用，执行PWM值的计算与更新
4. 确保函数执行时间短，避免阻塞中断处理
5. 使用原子操作处理共享资源访问
6. 提供清晰的函数接口定义和使用说明

## 实现方案

### 1. 结构体定义

```c
/**
 * @brief 舵机平滑控制状态结构体
 */
typedef struct {
    uint16 start_pwm;         // 起始PWM值
    uint16 target_pwm;        // 目标PWM值
    uint16 current_pwm;       // 当前PWM值
    uint16 update_count;       // 更新计数器
    uint8 update_enable;       // 更新使能标志
    float pwm_step;            // 每次PWM变化步长
    uint8 servo_channel;       // 舵机通道
    uint16 max_steps;          // 最大更新步数
} servo_smooth_control_t;
```

### 2. 初始化函数

```c
/**
 * @brief 初始化舵机平滑控制
 * @param servo 舵机平滑控制结构体指针
 * @param servo_channel 舵机通道
 * @param start_pwm 起始PWM值
 * @param target_pwm 目标PWM值
 * @param max_steps 最大更新步数，默认100
 * @return 初始化状态，0表示成功，非0表示失败
 */
int servo_smooth_control_init(servo_smooth_control_t *servo, uint8 servo_channel, uint16 start_pwm, uint16 target_pwm, uint16 max_steps)
{
    if (servo == NULL)
    {
        return -1; // 参数错误
    }

    // 原子操作设置结构体成员
    __disable_irq();
    servo->start_pwm = start_pwm;
    servo->target_pwm = target_pwm;
    servo->current_pwm = start_pwm;
    servo->update_count = 0;
    servo->update_enable = 1;
    servo->servo_channel = servo_channel;
    servo->max_steps = max_steps > 0 ? max_steps : 100;
    
    // 计算每次PWM变化步长
    servo->pwm_step = (float)(target_pwm - start_pwm) / servo->max_steps;
    __enable_irq();

    return 0; // 初始化成功
}
```

### 3. 更新函数（在中断服务程序中调用）

```c
/**
 * @brief 更新舵机平滑控制
 * @param servo 舵机平滑控制结构体指针
 * @return 当前PWM值
 */
uint16 servo_smooth_control_update(servo_smooth_control_t *servo)
{
    if (servo == NULL || !servo->update_enable)
    {
        return 0; // 参数错误或未使能
    }

    // 原子操作获取和更新状态
    __disable_irq();
    
    // 计算当前PWM值
    servo->current_pwm = servo->start_pwm + (uint16)(servo->pwm_step * servo->update_count);
    
    // 增加计数器
    servo->update_count++;
    
    // 达到最大步数后停止更新
    if (servo->update_count >= servo->max_steps)
    {
        servo->update_enable = 0;
        // 确保最终PWM值为目标值
        servo->current_pwm = servo->target_pwm;
    }
    
    uint16 current_pwm = servo->current_pwm;
    __enable_irq();

    return current_pwm; // 返回当前PWM值
}
```

### 4. 获取状态函数

```c
/**
 * @brief 获取舵机平滑控制状态
 * @param servo 舵机平滑控制结构体指针
 * @return 更新使能状态，1表示正在更新，0表示更新完成
 */
uint8 servo_smooth_control_get_status(servo_smooth_control_t *servo)
{
    if (servo == NULL)
    {
        return 0; // 参数错误
    }

    uint8 status;
    __disable_irq();
    status = servo->update_enable;
    __enable_irq();

    return status;
}
```

### 5. 在中断服务程序中的使用示例

```c
// 定义舵机平滑控制结构体
servo_smooth_control_t servo1_control;

// 100ms定时中断服务函数
void pit0_ch3_isr() // 定时器通道 3 周期中断服务函数 (100ms)
{
    pit_isr_flag_clear(PIT_CH3);
    
    // 检查舵机平滑控制是否启用
    if (servo_smooth_control_get_status(&servo1_control))
    {
        // 更新舵机PWM值
        uint16 pwm_value = servo_smooth_control_update(&servo1_control);
        
        // 根据舵机通道设置PWM值
        switch (servo1_control.servo_channel)
        {
            case 1:
                pwm_set_duty(SERVO_1, pwm_value);
                break;
            case 2:
                pwm_set_duty(SERVO_2, pwm_value);
                break;
            case 3:
                pwm_set_duty(SERVO_3, pwm_value);
                break;
            case 4:
                pwm_set_duty(SERVO_4, pwm_value);
                break;
            default:
                break;
        }
    }
}
```

### 6. 主函数中的使用示例

```c
// 初始化舵机平滑控制
servo_smooth_control_init(&servo1_control, 1, 1000, 2000, 100); // 舵机1，从1000到2000，100步

// 配置100ms定时中断
pit_init(PIT_CH3, 100000); // 100ms = 100000us
pit_interrupt_enable(PIT_CH3);
```

## 注意事项

1. 确保在系统初始化时正确配置PIT中断
2. 根据实际的PWM控制函数调整PWM值的更新方式
3. 确保中断服务函数的执行时间不超过中断周期，避免影响系统稳定性
4. 可以根据需要扩展该功能，例如支持多个舵机通道的平滑控制
5. 建议在使用前测试中断服务函数的执行时间，确保不会超过中断周期

## 优势

1. **独立性**：封装为独立的函数，可在不同的中断服务程序中复用
2. **安全性**：使用原子操作处理共享资源访问，确保在中断环境中的安全性
3. **灵活性**：支持自定义更新步数和目标PWM值
4. **实时性**：函数执行时间短，适合在中断服务程序中调用
5. **可扩展性**：支持多个舵机通道的平滑控制

该函数设计符合用户的要求，能够直接集成到中断处理流程中，实现舵机的实时平滑控制。
