# 按键与上位机（串口）使用说明

本文档对应 `Blalance_wheel_leg_Feis_v1.4` 工程当前行为：**电机使能仅由拨码 SWITCH1 决定**；串口可改速度基准，**不再存在「上位机接管电机」或速度锁（已无 M0/M1/Z/h 仲裁）**。

---

## 一、拨码开关

| 开关 | 作用 |
|------|------|
| **SWITCH1** | 电机总开关：`ON` 允许上电使能路径，`OFF` 关电机。 |
| **SWITCH2** | 速度档位：在档位**变化边沿**把全局基准 `motor_user_speed_cmd` 同步为 **1000** 或 **1500**（具体高低电平对应关系以 `control.c` 中 `motor_poll_switch2_speed_baseline()` 为准）。若先用串口 `V` 或 `q/r/s` 写了其它数值，**拨动 SWITCH2 仍会按档位覆盖为 1000/1500**。 |

### 轮速失控（Motor_Runaway_Latch）

触发后电机被**强制关闭**，且其它逻辑不能代替你开机。必须先 **SWITCH1 拨到 OFF**，锁存才会清除，之后才能再按 SWITCH1 正常上电。

---

## 二、实体按键（与菜单）

### 普通菜单页

| 按键 | 作用 |
|------|------|
| **KEY1** | 菜单「上」 |
| **KEY2** | 菜单「下」 |
| **KEY3** | 菜单「进入下一级」 |
| **KEY4** | 菜单「返回上一级」 |

仅在 **Motor_Switch 为关（电机关）** 时，菜单导航后会刷新屏幕（与 `selectMenu_Key` / `selectMenu` 逻辑一致）。

### 导航调试页（`MenuIsNavDebugPage()` 为真时）

| 按键 | 作用 |
|------|------|
| **KEY1** | 开始录制 `Nag_Begin_Record()` |
| **KEY2** | 请求停止录制 `Nag_Request_Stop_Record()` |
| **KEY3** | 录制中：循环元素类型；否则开始回放 `Nag_Begin_Replay()` |
| **KEY4** | 录制中：元素 enter/exit 打点；元素运行中：通知元素完成；否则同菜单「返回上一级」 |

## 三、上位机串口（VOFA / 无线串口路径）

数据由 `vofa.c` 的 `ReadDataFromPc()` 读入；**多字节速度帧**先经 `Menu_TryConsumePcMotorSpeedString()` 消费，其余首字节进入 `Menu_command`，由 `Menu.c` 的 `selectMenu()` 处理。

### 1. 速度：`V<数值>`

- **格式**：帧以 `V` 开头且总长 ≥ 2，例如 `V1200`、`V0`、`V-800`。
- **效果**：直接设置 `motor_user_speed_cmd`（**无速度锁**）。
- **与拨码关系**：之后若 **拨动 SWITCH2 改变档位**，仍会在边沿把基准改回 1000/1500。

### 2. 速度微调：`q` / `r` / `s`（单字节命令）

| 字符 | 作用 |
|------|------|
| **q** | `motor_user_speed_cmd += 500` |
| **r** | `motor_user_speed_cmd -= 500` |
| **s** | `motor_user_speed_cmd = 0` |

同样可被 **SWITCH2** 后续拨动覆盖为 1000/1500。

### 3. 菜单与导航（单字节 `a`～`v`，节选）

| 字符 | 作用（摘要） |
|------|----------------|
| a/b/c/d | 菜单 上/下/进子级/返回 |
| i | `jump_flag = 1` |
| j | 切换横滚平衡使能 |
| k / l / m | 导航录制开始 / 回放开始 / 请求停止录制 |
| n | 循环 `Nag_Vofa_Group` |
| o / p | 调试：自旋 / 相对转角请求 |
| t / u / v | 元素打点 / 切换录制元素类型 / 通知元素完成 |

（已移除：**h**、**M0/M1**、**Z** 等与电机接管、速度锁相关的约定。）

### 4. 其它串口扩展（`vofa.c`）

- **首字符为数字 `0`～`9`**：整包按浮点写入 `ReadBuf_Pid`（遗留调参入口，是否被其它模块使用以工程为准）。
- **`p1+` / `p1-` … `p4+` / `p4-`**（长度 ≥ 3）：调节腿 PWM 调试量 `pwm_ph1`～`pwm_ph4`（详见 `vofa.c` 注释；若调试腿伺服表需按注释临时关闭 `servo_control_table`）。

## 四、导航与速度环（必读）

- **未进入回放执行态**（`Nag_SystemRun_Index != 3`）时，`Nag_GetControlSpeedTarget()` 通常仍把速度目标门控为 **0**，因此仅改 `motor_user_speed_cmd` 未必立刻看到车速变化；需结合导航状态与 `Nag_Debug_Speed_Bypass_Enable`（见 `navigation.h`）理解现象。
- **回放执行态**下，目标速度由导航内部逻辑与录制数据等共同决定，用户基准仍参与前瞻/弯道等缩放；调车请以 VOFA 中 `speed_target_effective`、`N.Nag_SystemRun_Index` 为准。
